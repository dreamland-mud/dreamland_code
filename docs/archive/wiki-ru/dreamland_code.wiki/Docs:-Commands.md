# Основные команды

Взаимодействие с миром происходит с помощью команд, команды можно сокращать. Дальше рассказывается про самые важные из них. 

## Для общения
* `болтать`: сказать реплику на весь мир, например, `болт всем привет, я тут впервые`
* `сказать`: произнести реплику для тех, кто рядом, например, `ск да, помогу`

## Для информации
* `смотреть`: вывести описание комнаты или посмотреть на табличку, например, `см знак`, `см`
* `инв`ентарь, `эк`ипировка: посмотреть, что несет персонаж и что надето.
* `счет`: посмотреть параметры персонажа.
* `справка`: получить информации по команде или понятию, например, `справка опыт`. Все статьи справки [доступны на сайте](https://dreamland.rocks/help/).

## Для перемещения
* `с`евер, `ю`г, `в`осток, `з`апад, `вв`ерх, `вн`из: перейти в соседнюю комнату. Также можно перемещаться, используя стрелки на Num Pad.
* `возврат` или `/`: вернуться в свой родной город, если забрели слишком далеко

## Для сражений
* `убить`: напасть на монстра, например, `уб гоблин`
* `колдовать`: произнести волшебное заклинание, если вашему персонажу доступна магия, например, `к 'волш стрела' гоблин`
* `пинок`, `грязь`, `подножка`: различные активные боевые умения из числа доступных

## Для обучения
* `практика`: посмотреть список умений или выучить умение, стоя рядом с учителем, например, `прак кинжал`
* `тренировка`: повысить один из параметров персонажа, стоя рядом с тренером, например, `трен мудрость`

## Для предметов
* `надеть`: переместить предмет из инвентаря в экипировку, например, `над кинжал`
* `взять`: поднять предмет с пола, например, `взя факел`
* `бросить`: выбросить предмет из инвентаря на пол
* `дать`: отдать предмет другому персонажу, например, `дать бровь повар`

Можно увидеть меню со всеми действиями для предмета, если нажать на него.
