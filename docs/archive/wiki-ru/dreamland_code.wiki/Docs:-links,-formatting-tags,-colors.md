# Гипер-ссылки для вебклиента

Если обрамить текст специальными тегами (чаще всего начинающимися с символов `{h`), в веб-клиенте этот текст превратится в ссылку. По щелчку на эту ссылку выполнится определенная команда.
Закрывать тег можно как с помощью `{hx`, так и привычного `{x`.

* `{hhстарый мидгаард{hx` - превратится в вызов справки `help старый мидгаард`
* `{hcидти лестница{hx` - превратится в дословную команду `идти лестница`
* `{hgпроклятия{hx` - превратится в вызов `glist проклятия`
* `{hlhttps://google.com{hl` - превратится в обычную HTML ссылку. Она должна начинаться с http.

# Цвета

В зонах и во всех сообщениях можно использовать 16 ANSI-цветов. Справка `help colours` покажет, как задавать разные цвета в тексте.

Если разноцветное слово встречается в середине какого-то цветного сообщения, нужно внимательно следить, чтобы его расскраска не нарушила дальнейший цветной текст и не сбросила его в серый.

Например, у предмета с описанием `красивые {Bсиние{x галифе` в экипировке и инвентаре слово `галифе` будет окрашено не стандартным зеленым, а серым, т.к. цвет уже сбросили тегом `{x`. 
Решить эту проблему можно с помощью специальных тегов:
```
{1 - запомнить текущий цвет
{2 - восстановить цвет
```

Тогда описание предмета примет вид `красивые {1{Bсиние{2 галифе`, при этом цвет слова `галифе` будет таким, как требуют обстоятельства.
