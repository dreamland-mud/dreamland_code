# Очарование

## Как вычисляется количество очарованных существ (чармисов)

У умений `charm person`, `love potion`, `control animal`, `animate dead` есть проверка на наличие в группе слишком большого количества очарованных. Все остальные умения, такие как призыв големов, львов и т.д., не имеют этой проверки.

Максимальное количество чармисов для персонажа вычисляется так:
```
charisma_penalty = 25 - charisma
max_charmed = (intelligence / 4) + (level / 30) - charisma_penalty
```

Т.е. каждый параметр харизмы меньше `25` отнимет возможность очаровать еще одно существо. Каждые `4` очка ума добавят одного чармиса. Каждые `30` уровней опыта добавят одного чармиса.
Максимальное количество чармисов при уме 25 на 100м уровне равно `9`.

> Файлы: plug-ins/fight/magic.cpp

## Какие приказы можно отдавать 

Приказы (`order`) можно отдавать:
* очарованным существам, для которых вы - мастер
* игрокам в наручниках, если вы в клане рулеров

Каждый приказ проверяется на допустимость, т.к. далеко не все команды, даже если они синтаксически верны, можно приказать кому-то еще. Нельзя приказать свои собственные алиасы, они не учитываются.

Для определения допустимости приказа используется поле команды `order`, содержащая флаги из таблицы `.tables.order_flags`. С недавних пор этот поле выводится смертным по `command show <name>`.

Итак, команды, помеченные полями:
* `allow_ruler` (только от Правителей): можно приказать только игроку в наручниках
* `fight_only` (только в бою): можно приказать только сражающемуся чармису
* `player_only` (только игроки): можно приказать только очарованному персонажу другого игрока
* `thief_only` (только воры): можно приказать только мобу с `act` `thief`

> Файлы: plug-ins/comm/corder.cpp, plug-ins/command/command.cpp

## Как чармисы влияют на опыт

Любой очарованный моб, находившийся на момент убийства в одной комнате рядом с вами, отнимет немного опыта.
