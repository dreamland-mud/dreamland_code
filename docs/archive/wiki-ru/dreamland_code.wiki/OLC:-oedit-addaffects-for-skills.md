## Аффекты, влияющие на раскачку умений

С помощью редактора прототипов предметов `oedit` можно повесить на предмет аффекты, которые повлияют на знание тех или иных умений или целой группы умений, когда персонаж наденет этот предмет.
Например, можно добавить 10% к знаниям группы "проклятия", одновременно ухудшив знание умения "благословение" на 30%. 

Эти бонусы и антибонусы будут влиять только на те умения, которые уже доступны персонажу. То есть, после надевания предмета с бонусом на парирование 100%, это умение не появится внезапно раскачаным на 100%, если оно не было доступно изначально. Для добавления таких недоступных умений используйте [[скриптовый язык Феня|Fenia-skills]].

### Cинтаксис
```
addaffect learned <modifier> skills <умение>
addaffect learned <modifier> skill_groups <группа умений>
```

### Примеры
Улучшить знание группы `боевые заклинания`:
```
addaff learned 10 skill_groups combat
```

Ухудшить боевые навыки:
```
addaff learned -30 skill_groups fightmaster
```

Улучшить знание `благословения` (максимум всегда будет не больше 100%):
```
addaff learned 100 skills bless
```

## Аффекты, влияющие на уровень заклинаний

С помощью `oedit` можно также добавлять аффекты, влияющие на уровень произносимых заклинаний, как всех, так и какой-то конкретной группы или даже индивидуального заклинания. 

### Синтаксис

```
addaffect level <modifier>
addaffect level <modifier> skills <умение>
addaffect level <modifier> skill_groups <группа умений>
```

### Примеры
Усилить абсолютно все заклинания на 3:
```
addaff level 3
```

Ухудшить уровень заклинаний из группы `attack`:
```
addaff level -10 skill_groups attack
```

Усилить уровень заклинания `sanctuary`:
```
addaff level 3 skills sanctuary
```
